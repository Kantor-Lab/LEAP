# leap_control
This package contains code related to the movement and localization of the robot.

## Notes
As always, all the source files should have headers at the top explaining what they do and individual notes.

The `maps` folder contains actual representations of the maps. They were all generated by Billy's stuff and are not recreatable within this ros workspace. Be careful with pushing to github, some are quite large. `.ply`'s are pointcloud files that the lidar uses for ICP (see `leap_icp`). The `.pgm`'s and `.yaml`'s are 2d representations of those pointclouds flattened into occupancy grids. They are primarily used for navigation (see `leap_nav`) although they make for good visualization in foxglove too.

The `config` folder is pretty self explanatory, but I just want to mention that  `T_world_utm.txt` is the transformation from UTM to the world frame in `cmu.ply`. A transformation matrix is needed in order to use GPS for localization, and like the `maps` folder, is generated by Billy's stuff.
